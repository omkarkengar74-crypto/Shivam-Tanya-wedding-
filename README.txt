GitHub Pages वर प्रकाशित करण्यासाठी:
1. index.html आणि ishqq-hai.mp3 या दोन्ही फाइल्स तुमच्या GitHub repository च्या root मध्ये अपलोड करा.
2. जुन्या फाइल्स बदलून commit करा.
3. Settings > Pages मध्ये GitHub Pages सुरू असल्याची खात्री करा.
4. काही मिनिटांनी वेबसाइट उघडा. मोबाइलवर Chrome वापरू शकता.
